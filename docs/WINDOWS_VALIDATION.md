# Проверка первого этапа на Windows

Этот чек-лист остаётся обязательным: Linux build и headless UI tests не доказывают работу Windows WLAN API на реальном оборудовании. Следующие этапы не начинаются до аппаратной проверки базового сканирования.

1. На Windows 10/11 x64 с Wi-Fi адаптером запустить `publish/win-x64/WirelessSecurityAnalyzer.exe` вместе со всеми файлами публикации. Для этой проверки .NET Runtime устанавливать не нужно.
2. Проверить открытие окна, тёмную тему, все шесть пунктов sidebar и отсутствие ошибок в локальном журнале при навигации.
3. В разделе «Эфир» проверить, что отображается имя Wi-Fi адаптера. Нажать «Сканировать». Пока операция идёт, перемещать окно и переключать страницы: интерфейс должен отвечать.
4. Проверить реальные SSID/BSSID/RSSI/частоты/каналы/диапазоны, наличие скрытых сетей при их доступности, отображение Unicode SSID. Одинаковые SSID разных BSSID должны оставаться отдельными строками.
5. Повторить сканирование минимум 10 раз. Проверить отсутствие зависаний, рост числа handles в Process Explorer и использование памяти после серии операций.
6. Проверить поиск по SSID и BSSID, фильтры диапазона, обе последовательности сортировки по RSSI и пустые результаты фильтра.
7. Нажать «Отмена» во время scan; убедиться, что интерфейс выходит из busy-состояния и повторный scan работает. Закрыть окно во время scan; процесс должен завершиться без необработанного исключения.
8. При отсутствии Wi-Fi адаптера проверить сообщение «Wi-Fi адаптер не обнаружен». При отключённом адаптере / radio / airplane mode проверить сообщение и отсутствие падения.
9. При остановленной службе WLAN AutoConfig проверить понятное сообщение, затем включить службу и повторить scan.
10. При запрете Location permission проверить текст об ограничении Windows и кнопку открытия `ms-settings:privacy-location`; включить разрешение и повторить scan. Настройки зависят от версии Windows.
11. При наличии второго Wi-Fi адаптера проверить объединение одинаковых BSSID и работу остальных адаптеров при отказе одного.
12. Выполнить обычные тесты, затем отдельно включить аппаратный интеграционный тест по инструкции README.

Фиксировать версию Windows, модель/версию драйвера адаптера, результат каждой проверки и ошибки из локального журнала. Не включать реальные SSID/BSSID в публичные отчёты без необходимости.
